## SECTION 1: Deterministic Finite Automata (DFA)

### 1.1 DFA Construction

#### 1. Objective
Construct a formal, immutable Deterministic Finite Automaton (DFA) $M = (Q, \Sigma, \delta, q_0, F)$ from raw structural components, guaranteeing formal state-set and transition function integrity.

#### 2. Mathematical Definition
A DFA is a 5-tuple $M = (Q, \Sigma, \delta, q_0, F)$ where:
- $Q$ is a finite non-empty set of states.
- $\Sigma$ is a finite non-empty set of alphabet symbols.
- $\delta: Q \times \Sigma \to Q$ is a total transition function.
- $q_0 \in Q$ is the unique initial state.
- $F \subseteq Q$ is the set of accepting (final) states.

#### 3. Formal Inputs
- State set candidate $Q_{raw} = \{q_0, q_1, \dots, q_n\}$.
- Alphabet set candidate $\Sigma_{raw} = \{a_1, a_2, \dots, a_m\}$.
- Transition mapping candidate $\delta_{raw} \subset Q_{raw} \times \Sigma_{raw} \times Q_{raw}$.
- Designated initial state $q_{0, raw}$.
- Designated accepting set $F_{raw} \subseteq Q_{raw}$.

#### 4. Formal Outputs
- Immutable DFA tuple $M = (Q, \Sigma, \delta, q_0, F)$ or diagnostic validation failure array $V_{issues}$.

#### 5. Preconditions
- $Q_{raw} \neq \emptyset$.
- $\Sigma_{raw} \neq \emptyset$.
- $q_{0, raw} \in Q_{raw}$.
- $F_{raw} \subseteq Q_{raw}$.

#### 6. Postconditions
- For every state $q \in Q$ and symbol $\sigma \in \Sigma$, there exists exactly one $q' \in Q$ such that $\delta(q, \sigma) = q'$.
- State IDs in $Q$ are canonically ordered lexicographically.

#### 7. Internal State Representation
- $Q$: Sorted array of canonical string IDs `['q0', 'q1', ...]`.
- $\Sigma$: Sorted array of symbol characters `['a', 'b', ...]`.
- $\delta$: Two-dimensional lookup table `Map<StateId, Map<Symbol, StateId>>`.
- $q_0$: String StateId.
- $F$: `Set<StateId>`.

#### 8. Required Data Structures
- Canonical String Indexer.
- 2D Transition Matrix Map.
- Set Membership Index.

#### 9. Complete Step-by-Step Algorithm
1. Parse and sanitize input sets $Q_{raw}$ and $\Sigma_{raw}$, stripping whitespace and empty tokens.
2. Sort $Q$ lexicographically ($q_0 < q_1 < \dots < q_n$). Sort $\Sigma$ lexicographically ($a_1 < a_2 < \dots < a_m$).
3. Verify $q_0 \in Q$. If false, abort with `ERR_INITIAL_STATE_NOT_IN_Q`.
4. Verify $F \subseteq Q$. If false, abort with `ERR_ACCEPT_STATE_NOT_IN_Q`.
5. Initialize transition table matrix $\delta_{map}: Q \times \Sigma \to Q \cup \{\text{NULL}\}$.
6. For each tuple $(q, \sigma, q') \in \delta_{raw}$:
   - If $\delta_{map}[q][\sigma] \neq \text{NULL}$ and $\delta_{map}[q][\sigma] \neq q'$, abort with `ERR_DFA_NON_DETERMINISTIC`.
   - Set $\delta_{map}[q][\sigma] \leftarrow q'$.
7. Return immutable tuple $M = (Q, \Sigma, \delta_{map}, q_0, F)$.

#### 10. Intermediate States
- Unsorted candidate validation state $\to$ Canonically ordered index state $\to$ Completed transition matrix state.

#### 11. Determinism Rules
- Strict lexicographic sorting of state IDs and alphabet symbols guarantees unique, deterministic matrix indexing regardless of input entry order.

#### 12. Validation Rules
- $|\{q_0\}| = 1$.
- Total transition constraint: $|\delta(q, \sigma)| = 1$ for all $(q, \sigma) \in Q \times \Sigma$.

#### 13. Error Conditions
- `ERR_EMPTY_STATE_SET`: $Q = \emptyset$.
- `ERR_EMPTY_ALPHABET`: $\Sigma = \emptyset$.
- `ERR_MISSING_INITIAL_STATE`: $q_0 \notin Q$.
- `ERR_INVALID_ACCEPT_STATE`: $\exists q_f \in F : q_f \notin Q$.
- `ERR_DFA_NON_DETERMINISTIC`: Multiple destinations for pair $(q, \sigma)$.

#### 14. Edge Cases
- $Q = \{q_0\}$ with single self-loops for all $\sigma \in \Sigma$.
- $F = \emptyset$ (valid DFA accepting language $\emptyset$).

#### 15. Time Complexity
- Best Case: $O(|Q| \log |Q| + |\Sigma| \log |\Sigma|)$.
- Average Case: $O(|Q| \log |Q| + |\Sigma| \log |\Sigma| + |\delta|)$.
- Worst Case: $O(|Q| \log |Q| + |\Sigma| \log |\Sigma| + |Q| \cdot |\Sigma|)$.

#### 16. Space Complexity
- Memory Usage: $O(|Q| \cdot |\Sigma|)$ for total transition matrix.

#### 17. Correctness Guarantees
- Uniqueness Proof: Lexicographic ordering and matrix totality guarantee bi-directional mathematical isomorphism.

#### 18. Trace Generation Rules
- Emits `IConstructionTrace` payload recording validation status and formal 5-tuple JSON.

#### 19. AI Explanation Hooks
- `hook_explain_dfa_structure`: Exposes formal 5-tuple parameters and completeness status to AI Gateway.

#### 20. Unit Test Requirements
- Test construction with minimal 1-state DFA.
- Test rejection of non-deterministic transition inputs.
- Test rejection of initial state outside state set.

#### 21. Acceptance Criteria
- **Given** valid $Q=\{q_0, q_1\}$, $\Sigma=\{a, b\}$, $\delta(q_0, a)=q_1, \delta(q_0, b)=q_0, \delta(q_1, a)=q_0, \delta(q_1, b)=q_1$, $q_0$, $F=\{q_1\}$, **When** DFA Construction executes, **Then** valid immutable DFA tuple is returned.

#### 22. Complete Worked Example
- Input: $Q = \{q_1, q_0\}$, $\Sigma = \{b, a\}$, $\delta = \{(q_0, a, q_1), (q_0, b, q_0), (q_1, a, q_0), (q_1, b, q_1)\}$, $q_0 = q_0$, $F = \{q_1\}$.
- Ordering Pass: $Q = [q_0, q_1]$, $\Sigma = [a, b]$.
- Matrix Population: $\delta[q_0][a]=q_1, \delta[q_0][b]=q_0, \delta[q_1][a]=q_0, \delta[q_1][b]=q_1$.
- Output: Valid DFA $M$.

### 1.2 DFA Simulation & Acceptance

#### 1. Objective
Evaluate whether an input string $w \in \Sigma^*$ is accepted or rejected by a DFA $M$, generating a step-by-step execution trace.

#### 2. Mathematical Definition
Extend $\delta$ to $\hat{\delta}: Q \times \Sigma^* \to Q$:
- $\hat{\delta}(q, \varepsilon) = q$
- $\hat{\delta}(q, wa) = \delta(\hat{\delta}(q, w), a)$ for $w \in \Sigma^*, a \in \Sigma$

A string $w$ is accepted if $\hat{\delta}(q_0, w) \in F$; otherwise rejected.

#### 3. Formal Inputs
- Valid DFA $M = (Q, \Sigma, \delta, q_0, F)$.
- Input string $w = \sigma_1 \sigma_2 \dots \sigma_k$ where $\sigma_i \in \Sigma$.

#### 4. Formal Outputs
- `ISimulationTrace` containing array of `IExecutionStep` records and final decision (`HALT_ACCEPT` or `HALT_REJECT`).

#### 5. Preconditions
- $M$ is a valid total DFA.
- Every character in $w$ belongs to $\Sigma$.

#### 6. Postconditions
- Execution halts after exactly $|w|$ transition steps.
- $q_{final} = \hat{\delta}(q_0, w)$. Result is `HALT_ACCEPT` iff $q_{final} \in F$.

#### 7. Internal State Representation
- `current_state`: `StateId` initialized to $q_0$.
- `read_index`: Integer pointer $0 \le i \le k$.
- `trace_steps`: Accumulator array of step snapshots.

#### 8. Required Data Structures
- Step Trace Array.
- Fast Transition Lookup Map.

#### 9. Complete Step-by-Step Algorithm
1. Initialize $q_{curr} \leftarrow q_0$, $i \leftarrow 0$, $trace \leftarrow []$.
2. Record Step 0: $\{step: 0, state: q_0, consumed: \text{null}, remaining: w\}$.
3. While $i < |w|$:
   a. Let $\sigma \leftarrow w[i]$.
   b. If $\sigma \notin \Sigma$, halt with `ERR_UNRECOGNIZED_ALPHABET_SYMBOL`.
   c. Let $q_{next} \leftarrow \delta(q_{curr}, \sigma)$.
   d. Increment $i \leftarrow i + 1$.
   e. Let $remaining \leftarrow w[i \dots |w|-1]$.
   f. Record Step $i$: $\{step: i, state: q_{next}, consumed: \sigma, remaining: remaining\}$.
   g. Set $q_{curr} \leftarrow q_{next}$.
4. If $q_{curr} \in F$, set status $\leftarrow$ `HALT_ACCEPT`; else status $\leftarrow$ `HALT_REJECT`.
5. Return trace payload $\{input: w, finalState: q_{curr}, status: status, steps: trace\}$.

#### 10. Intermediate States
- Configuration sequence $(q_0, w) \vdash (q_1, w') \vdash \dots \vdash (q_k, \varepsilon)$.

#### 11. Determinism Rules
- Total transition mapping guarantees exactly one execution path for any string $w$.

#### 12. Validation Rules
- Verify $w[i] \in \Sigma$ for all $0 \le i < |w|$.

#### 13. Error Conditions
- `ERR_SYMBOL_NOT_IN_ALPHABET`: Symbol $\sigma_i \notin \Sigma$.
- `ERR_INCOMPLETE_DFA_TRANSITION`: Missing matrix entry during step execution.

#### 14. Edge Cases
- $w = \varepsilon$ (empty string): Evaluates $q_0 \in F$ directly in Step 0.

#### 15. Time Complexity
- Best Case: $O(|w|)$.
- Average Case: $O(|w|)$.
- Worst Case: $O(|w|)$.

#### 16. Space Complexity
- Memory Usage: $O(|w|)$ to store step trace log.

#### 17. Correctness Guarantees
- Induction on string length $|w|$ proves $\hat{\delta}(q_0, w)$ correctly reaches final state.

#### 18. Trace Generation Rules
- Emits immutable `ISimulationTrace` JSON matching `Schema_v1.0`.

#### 19. AI Explanation Hooks
- `hook_explain_simulation_step`: Exposes $(q_{curr}, \sigma, q_{next})$ step context to AI.

#### 20. Unit Test Requirements
- Test string evaluation on empty string $\varepsilon$.
- Test multi-step accepted string.
- Test multi-step rejected string.

#### 21. Acceptance Criteria
- **Given** DFA accepting even number of 'a's, **When** evaluating `aa`, **Then** trace completes in 2 steps with status `HALT_ACCEPT`.

#### 22. Complete Worked Example
- DFA: $q_0 \xrightarrow{a} q_1, q_1 \xrightarrow{a} q_0$, $F=\{q_0\}$, $w = \text{"aa"}$.
- Step 0: $q_0$, remaining "aa".
- Step 1: Consume 'a' $\to q_1$, remaining "a".
- Step 2: Consume 'a' $\to q_0$, remaining "".
- Result: $q_0 \in F \implies$ `HALT_ACCEPT`.

## SECTION 2: Non-Deterministic Finite Automata (NFA)

### 2.1 NFA Simulation & Branch Management

#### 1. Objective
Simulate multi-path non-deterministic execution of an NFA $M = (Q, \Sigma, \delta, q_0, F)$ on string $w$, evaluating set of active states $P \subseteq Q$.

#### 2. Mathematical Definition
Transition function maps to power set: $\delta: Q \times \Sigma \to \mathcal{P}(Q)$.
Extended transition function $\hat{\delta}: \mathcal{P}(Q) \times \Sigma^* \to \mathcal{P}(Q)$:
- $\hat{\delta}(P, \varepsilon) = P$
- $\hat{\delta}(P, wa) = \bigcup_{q \in \hat{\delta}(P, w)} \delta(q, a)$

String $w$ accepted iff $\hat{\delta}(\{q_0\}, w) \cap F \neq \emptyset$.

#### 3. Formal Inputs
- Valid NFA $M = (Q, \Sigma, \delta, q_0, F)$.
- Input string $w \in \Sigma^*$.

#### 4. Formal Outputs
- `ISimulationTrace` containing active state set configurations and decision (`HALT_ACCEPT` or `HALT_REJECT`).

#### 5. Preconditions
- $M$ is a valid NFA.
- $w[i] \in \Sigma$ for all $i$.

#### 6. Postconditions
- Final active set $P_{final} = \hat{\delta}(\{q_0\}, w)$.
- Accepted iff $P_{final} \cap F \neq \emptyset$.

#### 7. Internal State Representation
- `active_states`: `Set<StateId>` sorted lexicographically.
- `branch_tree`: Tree structure recording parent-child state path lineage.

#### 8. Required Data Structures
- Active State Set (`Set<StateId>`).
- Path Lineage Tree Node.

#### 9. Complete Step-by-Step Algorithm
1. Initialize $P_{curr} \leftarrow \{q_0\}$, $i \leftarrow 0$.
2. Record Step 0: $\{step: 0, activeStates: [q_0], consumed: \text{null}, remaining: w\}$.
3. While $i < |w|$ and $P_{curr} \neq \emptyset$:
   a. Let $\sigma \leftarrow w[i]$.
   b. Let $P_{next} \leftarrow \emptyset$.
   c. For each state $q \in P_{curr}$:
      i. Let $NextStates \leftarrow \delta(q, \sigma)$.
      ii. $P_{next} \leftarrow P_{next} \cup NextStates$.
   d. Sort $P_{next}$ lexicographically.
   e. Increment $i \leftarrow i + 1$.
   f. Record Step $i$: $\{step: i, activeStates: P_{next}, consumed: \sigma, remaining: w[i\dots]\}$.
   g. Set $P_{curr} \leftarrow P_{next}$.
4. If $P_{curr} \cap F \neq \emptyset$, status $\leftarrow$ `HALT_ACCEPT`; else status $\leftarrow$ `HALT_REJECT`.
5. Return trace payload.

#### 10. Intermediate States
- Configuration sequence $(P_0, w) \vdash (P_1, w') \vdash \dots \vdash (P_k, \varepsilon)$.

#### 11. Determinism Rules
- Sorting $P_{next}$ lexicographically ensures deterministic active state set ordering at every step.

#### 12. Validation Rules & Implementation Safeguards
- **Configurable Execution Budgets (`IExecutionBudget`)**: Rather than hardcoded thresholds, active path expansion and branch tracking respect environment-configured execution budgets (`IExecutionBudget.maxActivePaths`).
- **Deterministic Budget Safeguard**: If active branching during any simulation step exceeds `IExecutionBudget.maxActivePaths`, the solver MUST terminate deterministically and return `ERR_SIMULATION_PATH_LIMIT_EXCEEDED`.
- **Non-Rejection Policy**: Budget exhaustion is strictly documented as an infrastructure implementation safeguard to protect system resources, NOT as a mathematical string rejection. Acceptance of a string must never silently fail or misclassify due to budget exhaustion.

#### 13. Error Conditions
- `ERR_SIMULATION_PATH_LIMIT_EXCEEDED`: Active computation branches exceeded `IExecutionBudget.maxActivePaths` threshold. Simulation terminates deterministically with diagnostic error payload.
- `ERR_SYMBOL_NOT_IN_ALPHABET`: Symbol $\sigma_i \notin \Sigma$.

#### 14. Edge Cases
- $P_{curr} = \emptyset$ (deadlock across all branches): Halts immediately with `HALT_REJECT`.

#### 15. Time Complexity
- Best Case: $O(|w|)$.
- Worst Case: $O(|w| \cdot |Q|^2)$.

#### 16. Space Complexity
- Memory Usage: $O(|w| \cdot |Q|)$.

#### 17. Correctness Guarantees
- Mathematical induction over $|w|$ proves $P_{final}$ contains all reachable computation states.

#### 18. Trace Generation Rules
- Emits branch tree trace with parent-child transition linkages.

#### 19. AI Explanation Hooks
- `hook_explain_nfa_branching`: Exposes active state set $P_{curr}$ and multi-path choices to AI.

#### 20. Unit Test Requirements
- Test NFA branching on single symbol to multiple states.
- Test NFA deadlock state termination.

#### 21. Acceptance Criteria
- **Given** NFA where $\delta(q_0, a) = \{q_0, q_1\}$, **When** evaluating symbol 'a', **Then** active state set becomes $\{q_0, q_1\}$.

#### 22. Complete Worked Example
- NFA: $\delta(q_0, a) = \{q_0, q_1\}$, $\delta(q_1, b) = \{q_2\}$, $F=\{q_2\}$, $w = \text{"ab"}$.
- Step 0: $P_0 = \{q_0\}$.
- Step 1 ('a'): $P_1 = \{q_0, q_1\}$.
- Step 2 ('b'): $P_2 = \delta(q_0, b) \cup \delta(q_1, b) = \emptyset \cup \{q_2\} = \{q_2\}$.
- Result: $P_2 \cap F = \{q_2\} \neq \emptyset \implies$ `HALT_ACCEPT`.

## SECTION 3: $\epsilon$-NFA Solvers & $\epsilon$-Closure

### 3.1 $\epsilon$-Closure Computation

#### 1. Objective
Compute the $\epsilon$-closure $\text{ECL}(R)$ for a state set $R \subseteq Q$ in an $\epsilon$-NFA, finding all states reachable via zero or more $\epsilon$-transitions.

#### 2. Mathematical Definition
For a state $q \in Q$, $\text{ECL}(q)$ is the smallest set satisfying:
1. $q \in \text{ECL}(q)$
2. If $p \in \text{ECL}(q)$ and $r \in \delta(p, \varepsilon)$, then $r \in \text{ECL}(q)$

For a set $R \subseteq Q$:
$$\text{ECL}(R) = \bigcup_{q \in R} \text{ECL}(q)$$

#### 3. Formal Inputs
- $\epsilon$-NFA $M = (Q, \Sigma, \delta, q_0, F)$.
- Target state set $R \subseteq Q$.

#### 4. Formal Outputs
- Closed state set $\text{ECL}(R) \subseteq Q$, sorted lexicographically.

#### 5. Preconditions
- $R \subseteq Q$.
- $\delta$ includes mappings for symbol $\varepsilon$.

#### 6. Postconditions
- $\text{ECL}(R) \supseteq R$.
- No state $p \in \text{ECL}(R)$ has an unvisited $\varepsilon$-transition $r \in \delta(p, \varepsilon)$ such that $r \notin \text{ECL}(R)$.

#### 7. Internal State Representation
- `stack`: Depth-First Search / Breadth-First Search worklist.
- `closure_set`: `Set<StateId>`.

#### 8. Required Data Structures
- Worklist Stack / Queue (`StateId[]`).
- Visited Set (`Set<StateId>`).

#### 9. Complete Step-by-Step Algorithm
1. Initialize $closure \leftarrow \emptyset$, $stack \leftarrow []$.
2. Sort input set $R$ lexicographically.
3. For each state $q \in R$:
   a. Add $q$ to $closure$.
   b. Push $q$ onto $stack$.
4. While $stack \neq \emptyset$:
   a. Pop $p \leftarrow stack.pop()$.
   b. Let $EpsTargets \leftarrow \delta(p, \varepsilon)$.
   c. For each state $r \in EpsTargets$:
      i. If $r \notin closure$:
         - Add $r$ to $closure$.
         - Push $r$ onto $stack$.
5. Convert $closure$ to array, sort lexicographically, and return.

#### 10. Intermediate States
- Iterative expansion of $closure$ set until fixed-point $closure^{(k+1)} = closure^{(k)}$ is reached.

#### 11. Determinism Rules
- Standardized DFS/BFS processing order over sorted input sets guarantees identical traversal order.

#### 12. Validation Rules
- Loop detection: Visited set prevents infinite recursion on cyclic $\epsilon$-paths ($q_0 \xrightarrow{\varepsilon} q_1 \xrightarrow{\varepsilon} q_0$).

#### 13. Error Conditions
- `ERR_CYCLE_RECURSION_LIMIT`: Exceeded maximum stack depth (handled safely via Visited Set).

#### 14. Edge Cases
- $\delta(q, \varepsilon) = \emptyset$ for all $q \in R \implies \text{ECL}(R) = R$.

#### 15. Time Complexity
- Best Case: $O(|R|)$.
- Worst Case: $O(|Q| + |\delta_\varepsilon|)$.

#### 16. Space Complexity
- Memory Usage: $O(|Q|)$.

#### 17. Correctness Guarantees
- Fixed-Point Theorem: Algorithm terminates because $Q$ is finite and $closure$ grows monotonically ($|closure| \le |Q|$).

#### 18. Trace Generation Rules
- Emits $\epsilon$-closure expansion steps for visual debugging.

#### 19. AI Explanation Hooks
- `hook_explain_epsilon_closure`: Exposes initial set $R$ and spontaneous hop additions to AI.

#### 20. Unit Test Requirements
- Test $\epsilon$-closure with zero $\epsilon$-transitions.
- Test $\epsilon$-closure with linear chain $q_0 \xrightarrow{\varepsilon} q_1 \xrightarrow{\varepsilon} q_2$.
- Test $\epsilon$-closure with cyclic path $q_0 \xrightarrow{\varepsilon} q_1 \xrightarrow{\varepsilon} q_0$.

#### 21. Acceptance Criteria
- **Given** $\delta(q_0, \varepsilon) = \{q_1\}$, $\delta(q_1, \varepsilon) = \{q_2\}$, **When** computing $\text{ECL}(\{q_0\})$, **Then** result is $\{q_0, q_1, q_2\}$.

#### 22. Complete Worked Example
- $\delta(q_0, \varepsilon) = \{q_1\}$, $\delta(q_1, \varepsilon) = \{q_2\}$. Input $R = \{q_0\}$.
- Init: $closure = \{q_0\}$, $stack = [q_0]$.
- Pop $q_0 \to \varepsilon$-targets $\{q_1\}$. Add $q_1 \to closure = \{q_0, q_1\}$, $stack = [q_1]$.
- Pop $q_1 \to \varepsilon$-targets $\{q_2\}$. Add $q_2 \to closure = \{q_0, q_1, q_2\}$, $stack = [q_2]$.
- Pop $q_2 \to \varepsilon$-targets $\emptyset$. $stack = []$.
- Return sorted: $[q_0, q_1, q_2]$.

## SECTION 4: Conversions

### 4.1 NFA to DFA Conversion (Subset Construction)

#### 1. Objective
Convert an NFA $M_N = (Q_N, \Sigma, \delta_N, q_{0,N}, F_N)$ into an equivalent deterministic DFA $M_D = (Q_D, \Sigma, \delta_D, q_{0,D}, F_D)$ using Subset / Power Set Construction.

#### 2. Mathematical Definition
- $q_{0,D} = \text{ECL}(\{q_{0,N}\})$
- $Q_D \subseteq \mathcal{P}(Q_N)$
- $\delta_D(P, a) = \text{ECL}\left( \bigcup_{q \in P} \delta_N(q, a) \right)$ for $P \in Q_D, a \in \Sigma$
- $F_D = \{P \in Q_D \mid P \cap F_N \neq \emptyset\}$

#### 3. Formal Inputs
- Input NFA $M_N = (Q_N, \Sigma, \delta_N, q_{0,N}, F_N)$.

#### 4. Formal Outputs
- Equivalent DFA $M_D = (Q_D, \Sigma, \delta_D, q_{0,D}, F_D)$ and `IConversionResult` trace log.

#### 5. Preconditions
- $M_N$ is a valid NFA / $\epsilon$-NFA.

#### 6. Postconditions
- $L(M_D) = L(M_N)$.
- $M_D$ is a valid total DFA over alphabet $\Sigma$.

#### 7. Internal State Representation
- `subset_map`: Map assigning canonical DFA state IDs (`D0`, `D1`, ...) to NFA state sets ($P \subseteq Q_N$).
- `unmarked_subsets`: Queue of unprocessed DFA states.

#### 8. Required Data Structures
- Subset Dictionary (`Map<string, StateId>`).
- Worklist Queue (`Set<StateId>[]`).

#### 9. Complete Step-by-Step Algorithm
1. Let $s_0 \leftarrow \text{ECL}(\{q_{0,N}\})$. Sort $s_0$ lexicographically.
2. Assign $s_0$ canonical label `D0`. Set $q_{0,D} \leftarrow \text{`D0'}$.
3. Initialize $Q_D \leftarrow \{\text{`D0'}\}$, $subsets \leftarrow \{\text{`D0'}: s_0\}$, $queue \leftarrow [\text{`D0'}]$.
4. Initialize transition table $\delta_D$.
5. While $queue \neq \emptyset$:
   a. Pop $D_i \leftarrow queue.shift()$.
   b. Let $P \leftarrow subsets[D_i]$.
   c. For each symbol $a \in \Sigma$ (in lexicographical order):
      i. Let $U \leftarrow \bigcup_{q \in P} \delta_N(q, a)$.
      ii. Let $U_{closed} \leftarrow \text{ECL}(U)$. Sort $U_{closed}$ lexicographically.
      iii. If $U_{closed} == \emptyset$:
           - Create/reference Dead State `D_dead` in $Q_D$. Set $\delta_D(D_i, a) \leftarrow \text{`D_dead'}$.
      iv. Else:
           - Check if $U_{closed}$ already exists in $subsets$.
           - If exists, let $D_j$ be its label.
           - Else:
             - Generate next canonical label $D_j \leftarrow \text{`D'} + |Q_D|$.
             - Add $D_j$ to $Q_D$, set $subsets[D_j] \leftarrow U_{closed}$, push $D_j$ to $queue$.
           - Set $\delta_D(D_i, a) \leftarrow D_j$.
6. Compute $F_D \leftarrow \{D_k \in Q_D \mid subsets[D_k] \cap F_N \neq \emptyset\}$.
7. Return $M_D = (Q_D, \Sigma, \delta_D, q_{0,D}, F_D)$ and conversion step log.

#### 10. Intermediate States
- Unprocessed subset queue state $\to$ Mapping table state $\to$ Final DFA state graph.

#### 11. Determinism Rules
- Lexicographical sorting of NFA state sets and alphabet symbols guarantees deterministic, unique DFA state labeling (`D0`, `D1`, ...).

#### 12. Validation Rules
- Equivalent-solution validation: Manual student mode checks set equality $P_{student} == P_{canonical}$ regardless of element order.

#### 13. Error Conditions
- `ERR_POWERSET_EXPLOSION`: NFA states $|Q_N| > 12$ triggers paginated subset mode.

#### 14. Edge Cases
- Empty language NFA generates 1-state DFA pointing to dead state.

#### 15. Time Complexity
- Best Case: $O(|Q_N| \cdot |\Sigma|)$.
- Worst Case: $O(2^{|Q_N|} \cdot |\Sigma|)$.

#### 16. Space Complexity
- Memory Usage: $O(2^{|Q_N|} \cdot |\Sigma|)$.

#### 17. Correctness Guarantees
- Rabin-Scott Theorem: Proves power set construction constructs exact deterministic simulator for any NFA.

#### 18. Trace Generation Rules
- Emits detailed step trace listing each subset creation step and transition map entry.

#### 19. AI Explanation Hooks
- `hook_explain_subset_construction`: Exposes subset mappings (e.g. `D1 = {q0, q1}`) to AI.

#### 20. Unit Test Requirements
- Test single-state NFA conversion.
- Test NFA with $\epsilon$-transitions conversion.
- Test NFA producing dead states in subset construction.

#### 21. Acceptance Criteria
- **Given** NFA for $(a+b)*ab$, **When** subset construction runs, **Then** output is valid total DFA with canonical state IDs.

#### 22. Complete Worked Example
- NFA: $\delta(q_0, a)=\{q_0, q_1\}, \delta(q_0, b)=\{q_0\}, \delta(q_1, b)=\{q_2\}$, $F=\{q_2\}$.
- $D_0 = \{q_0\}$.
- $\delta_D(D_0, a) = \{q_0, q_1\} \to \text{new } D_1$.
- $\delta_D(D_0, b) = \{q_0\} \to D_0$.
- $\delta_D(D_1, a) = \{q_0, q_1\} \to D_1$.
- $\delta_D(D_1, b) = \{q_0, q_2\} \to \text{new } D_2$ (Accepting, since $q_2 \in F$).
- Final DFA: 3 states $\{D_0, D_1, D_2\}$.

### 4.2 DFA Minimization (Hopcroft's Algorithm)

#### 1. Objective
Minimize a DFA $M = (Q, \Sigma, \delta, q_0, F)$ to its canonical minimum-state equivalent $M_{min}$ in $O(|\Sigma| \cdot |Q| \log |Q|)$ time using Hopcroft's Partition Refinement Algorithm.

#### 2. Mathematical Definition
Find coarsest equivalence partition $P$ of $Q$ such that for all $p, q \in B \in P$ and all $a \in \Sigma$, $\delta(p, a)$ and $\delta(q, a)$ belong to the same block in $P$.

#### 3. Formal Inputs
- Total DFA $M = (Q, \Sigma, \delta, q_0, F)$ with no unreachable states.

#### 4. Formal Outputs
- Minimal DFA $M_{min} = (Q_{min}, \Sigma, \delta_{min}, q_{0,min}, F_{min})$.

#### 5. Preconditions
- Unreachable states pruned from $M$ prior to partitioning.
- $M$ is total over $\Sigma$.

#### 6. Postconditions
- $M_{min}$ is isomorphic to any minimal DFA accepting $L(M)$.
- $|Q_{min}| \le |Q|$.

#### 7. Internal State Representation
- `P`: Array of state blocks `Set<StateId>[]`.
- `W`: Worklist set of splitting blocks `Set<StateId>[]`.

#### 8. Required Data Structures
- Block Partition Array (`Set<StateId>[]`).
- Splitter Worklist Queue.

#### 9. Complete Step-by-Step Algorithm
1. Prune unreachable states from $Q$ using BFS from $q_0$.
2. Initial Partition: $P \leftarrow \{F, Q \setminus F\}$. (Omit empty sets).
3. Initial Worklist: $W \leftarrow \{F, Q \setminus F\}$. (Choose smaller block for $W$).
4. While $W \neq \emptyset$:
   a. Pop block $A \leftarrow W.shift()$.
   b. For each symbol $c \in \Sigma$ (lexicographically):
      i. Let $X \leftarrow \{q \in Q \mid \delta(q, c) \in A\}$ (pre-image of $A$ under $c$).
      ii. For each block $Y \in P$ where $Y \cap X \neq \emptyset$ and $Y \setminus X \neq \emptyset$:
          - Replace $Y$ in $P$ with $Y_1 \leftarrow Y \cap X$ and $Y_2 \leftarrow Y \setminus X$.
          - If $Y \in W$:
            - Replace $Y$ in $W$ with $Y_1$ and $Y_2$.
          - Else:
            - If $|Y_1| \le |Y_2|$, push $Y_1$ to $W$; else push $Y_2$ to $W$.
5. Reconstruct minimal DFA $M_{min}$:
   - Each partition block $B \in P$ becomes a state in $Q_{min}$.
   - Sort blocks lexicographically by lowest contained original state ID.
   - Assign canonical IDs `M0`, `M1`, ...
   - $q_{0,min} \leftarrow$ block containing $q_0$.
   - $F_{min} \leftarrow$ blocks containing states from $F$.
   - $\delta_{min}(B_i, c) \leftarrow$ block containing $\delta(q, c)$ for $q \in B_i$.
6. Return $M_{min}$.

#### 10. Intermediate States
- $P^{(0)} = \{F, Q \setminus F\} \to P^{(1)} \to \dots \to P_{final}$.

#### 11. Determinism Rules
- Sorting partition blocks by minimum original state ID guarantees deterministic state naming (`M0`, `M1`, ...).

#### 12. Validation Rules
- Verify $M_{min}$ language equivalence against original $M$ via product automaton equivalence test.

#### 13. Error Conditions
- `ERR_EMPTY_DFA`: $Q = \emptyset$.

#### 14. Edge Cases
- All states accepting ($F = Q$) or zero states accepting ($F = \emptyset$) $\implies$ minimizes to 1-state DFA.

#### 15. Time Complexity
- Best Case: $O(|Q|)$.
- Worst Case: $O(|\Sigma| \cdot |Q| \log |Q|)$.

#### 16. Space Complexity
- Memory Usage: $O(|Q| + |\Sigma|)$.

#### 17. Correctness Guarantees
- Myhill-Nerode Theorem: Guarantees unique minimal DFA up to state renaming isomorphism.

#### 18. Trace Generation Rules
- Emits partition splitting steps showing block refinements $(Y \to Y_1, Y_2)$.

#### 19. AI Explanation Hooks
- `hook_explain_minimization_split`: Exposes pre-image $X$ and splitting rationale to AI.

#### 20. Unit Test Requirements
- Test minimization on already minimal DFA (returns identical state count).
- Test minimization on DFA with redundant equivalent states.

#### 21. Acceptance Criteria
- **Given** a 4-state DFA with 2 equivalent states, **When** Hopcroft minimization executes, **Then** output is 3-state minimal DFA.

#### 22. Complete Worked Example
- States $\{q_0, q_1, q_2\}$, $F=\{q_1, q_2\}$. Both $q_1, q_2$ have identical transitions to $q_0$ on 'a'.
- Init Partition: $P = \{\{q_0\}, \{q_1, q_2\}\}$.
- Splitter check shows $q_1, q_2$ cannot be distinguished by any string $\implies$ no split occurs.
- Minimal DFA has 2 states: `M0` = $\{q_0\}$, `M1` = $\{q_1, q_2\}$.

### 4.3 DFA to Regular Expression Conversion (State Elimination)

#### 1. Objective
Convert a total DFA $M = (Q, \Sigma, \delta, q_0, F)$ into an equivalent Regular Expression $R$ using the State Elimination Algorithm under a canonical elimination ordering policy.

#### 2. Mathematical Definition
Construct Generalized Transition Graph (GTG) with start state $q_{start}$ and final state $q_{final}$. Repeatedly eliminate internal states $q_k \notin \{q_{start}, q_{final}\}$ updating regular expression labels along paths $p \to q_k \to r$:
$$R_{pr}' = R_{pr} + R_{pk} R_{kk}^* R_{kr}$$

#### 3. Canonical Elimination Ordering Policy
- **Preserved States**: The initial state $q_0$ and accepting states $F$ MUST be preserved during internal elimination iterations.
- **Lexicographical Elimination Policy**: Internal states $Q_{internal} = Q \setminus (\{q_0\} \cup F)$ MUST be eliminated strictly in ascending lexicographical order of their state IDs ($q_1 < q_2 < \dots < q_m$).
- **RegEx Expression Normalization**: Mathematically equivalent regular expressions generated across different elimination orders are intentionally normalized to a single canonical AST representation.

#### 4. Step-by-Step Algorithm
1. Initialize GTG with new start state $q_{start}$ ($\varepsilon$-transition to $q_0$) and new final state $q_{final}$ ($\varepsilon$-transitions from all $q_f \in F$).
2. Collect internal states $Q_{internal} \leftarrow Q \setminus (\{q_0\} \cup F)$.
3. Sort $Q_{internal}$ lexicographically.
4. For each state $q_k \in Q_{internal}$ (in lexicographical order):
   a. For each predecessor $p \neq q_k$ and successor $r \neq q_k$:
      i. Update label $R_{pr} \leftarrow R_{pr} + R_{pk}(R_{kk})^* R_{kr}$.
   b. Remove state $q_k$ and all incident edges from GTG.
5. Simplify final expression $R_{start, final}$ to produce canonical RegEx string.
6. Return canonical RegEx string and conversion trace.

### 4.4 Regular Expression to $\epsilon$-NFA Conversion (Thompson's Construction)

#### 1. Objective
Convert a parsed Regular Expression AST into an equivalent $\epsilon$-NFA $M = (Q, \Sigma, \delta, q_0, F)$ using Thompson's Structural Construction Algorithm.

#### 2. Mathematical Definition & Inductive Rules
Construct $\epsilon$-NFA fragments recursively over AST node types:
1. **Base Symbol Node ($a \in \Sigma$)**:
   - Create initial state $i$ and accepting state $f$.
   - Transition: $\delta(i, a) = \{f\}$.
2. **Epsilon Node ($\varepsilon$)**:
   - Create initial state $i$ and accepting state $f$.
   - Transition: $\delta(i, \varepsilon) = \{f\}$.
3. **Union Node ($R_1 + R_2$)**:
   - Create new start state $i$ and final state $f$.
   - Transitions: $\delta(i, \varepsilon) = \{i_1, i_2\}$, $\delta(f_1, \varepsilon) = \{f\}$, $\delta(f_2, \varepsilon) = \{f\}$.
4. **Concatenation Node ($R_1 \cdot R_2$)**:
   - Connect $f_1$ to $i_2$ via $\varepsilon$-transition: $\delta(f_1, \varepsilon) = \{i_2\}$.
   - Start state is $i_1$, final state is $f_2$.
5. **Kleene Star Node ($R^*$)**:
   - Create new start state $i$ and final state $f$.
   - Transitions: $\delta(i, \varepsilon) = \{i_1, f\}$, $\delta(f_1, \varepsilon) = \{i_1, f\}$.

#### 3. Canonical Ordering & State Naming Policy
- State IDs are allocated sequentially (`T0`, `T1`, `T2`, ...) during post-order AST traversal, guaranteeing deterministic state ID assignment.

#### 4. Step-by-Step Algorithm
1. Perform post-order traversal on RegEx AST root node.
2. For each AST node, construct corresponding $\epsilon$-NFA fragment using Inductive Rules.
3. Assign canonical state IDs `T0`, `T1`, ... sequentially.
4. Set initial state $q_0 \leftarrow i_{root}$ and accepting set $F \leftarrow \{f_{root}\}$.
5. Collect all generated states into $Q$ and transitions into $\delta$.
6. Return immutable $\epsilon$-NFA tuple $M = (Q, \Sigma, \delta, q_0, F)$ and conversion trace log.

## SECTION 5: Real-Time Static Validation Engine

### 5.1 Validation Suite Algorithms

#### 1. Objective
Execute static mathematical linting on active model representations, detecting structural defects, non-determinism, unreachable states, and missing transitions.

#### 2. Mathematical Definition & Algorithms
1. **Reachability Analysis (BFS)**:
   - Compute $Q_{reachable} = \{q \in Q \mid \exists w \in \Sigma^* : \hat{\delta}(q_0, w) = q\}$.
   - Unreachable set: $Q_{unreachable} = Q \setminus Q_{reachable}$.
2. **Dead State Analysis**:
   - Compute $Q_{useful} = \{q \in Q \mid \exists w \in \Sigma^* : \hat{\delta}(q, w) \in F\}$.
   - Dead set: $Q_{dead} = Q \setminus Q_{useful}$.
3. **DFA Determinism & Completeness**:
   - For each $q \in Q, a \in \Sigma$: verify $|\delta(q, a)| = 1$.
   - If 0: flag `ERR_DFA_INCOMPLETE`. If $>1$: flag `ERR_DFA_NON_DETERMINISTIC`.

#### 3. Formal Inputs
- Candidate automaton model $M = (Q, \Sigma, \delta, q_0, F)$.

#### 4. Formal Outputs
- Array of structured `IValidationIssue` records.

#### 5. Preconditions
- Model data structures loaded into solver memory.

#### 6. Postconditions
- Returns empty issue array iff model is mathematically valid for its designated mode (DFA/NFA/$\epsilon$-NFA).

#### 7. Internal State Representation
- Configurable execution limits: `IExecutionBudget` (max state threshold for synchronous vs worker execution).

#### 8. Required Data Structures
- Visited Set (`Set<StateId>`).
- Diagnostic Issue Collection (`IValidationIssue[]`).

#### 9. Complete Step-by-Step Algorithm
1. Initialize $issues \leftarrow []$.
2. **Initial State Check**: If $q_0 \notin Q$ or $|q_0| \neq 1$, push `ERR_INITIAL_STATE_INVALID`.
3. **Alphabet Check**: Verify $\Sigma \neq \emptyset$ and no blank symbol tokens.
4. **Reachability Pass**: Run BFS from $q_0$. For any $q \in Q \setminus Q_{vis}$, push `WARN_UNREACHABLE_STATE(q)`.
5. **Dead State Pass**: Run reverse BFS from $F$. For any $q \in Q \setminus Q_{useful}$ (excluding designated sink state), push `WARN_DEAD_STATE(q)`.
6. **Mode Checks (DFA)**:
   - For each $q \in Q, a \in \Sigma$:
     - Let $cnt \leftarrow |\delta(q, a)|$.
     - If $cnt == 0$, push `ERR_DFA_INCOMPLETE(q, a)`.
     - If $cnt > 1$, push `ERR_DFA_NON_DETERMINISTIC(q, a)`.
7. Return $issues$.

#### 10. Intermediate States
- Pre-validation pass $\to$ Graph traversal pass $\to$ Diagnostic report aggregation.

#### 11. Determinism Rules
- Lexicographical iteration over states and alphabet symbols produces deterministically ordered issue arrays.

#### 12. Validation Rules
- Issues categorized by severity: `ERROR` (blocks simulation), `WARNING` (non-blocking notification), `INFO`.

#### 13. Error Conditions
- Handled defensively; malformed models return fatal `ERR_MALFORMED_MODEL_STRUCTURE`.

#### 14. Edge Cases
- Graph with zero accepting states ($F = \emptyset$) flags `WARN_NO_ACCEPTING_STATES`.

#### 15. Time Complexity
- Synchronous Mode ($|Q| \le 100$): $O(|Q| + |\delta|)$.
- Asynchronous Worker Mode ($|Q| > 100$): Offloaded with debounced scheduling.

#### 16. Space Complexity
- Memory Usage: $O(|Q| + |\delta|)$.

#### 17. Correctness Guarantees
- Graph reachability algorithms guarantee complete discovery of all isolated subgraphs.

#### 18. Trace Generation Rules
- Emits diagnostic validation report for UI badge rendering.

#### 19. AI Explanation Hooks
- `hook_explain_validation_issue`: Exposes violated formal theorem and remediation advice to AI.

#### 20. Unit Test Requirements
- Test validation on valid total DFA (0 issues).
- Test validation on DFA with missing transition.
- Test validation on NFA with unreachable state.

#### 21. Acceptance Criteria
- **Given** a DFA with state $q_0$ lacking transition for 'b', **When** validation runs, **Then** `ERR_DFA_INCOMPLETE` issue is returned with auto-fix payload.

#### 22. Complete Worked Example
- DFA: $Q=\{q_0, q_1\}$, $\Sigma=\{a, b\}$, $\delta(q_0, a)=q_1$.
- Validation Pass: Check $(q_0, b) \to$ missing!
- Output: `[IValidationIssue { code: 'ERR_DFA_INCOMPLETE', stateId: 'q0', symbol: 'b' }]`.

## SECTION 6: Simulation Engine Controls

### 6.1 State Machine Simulation Pipeline

#### 1. Objective
Orchestrate real-time step execution, playback, pause, resume, reset, trace recording, and undo/redo history for simulation playback.

#### 2. Mathematical Definition
Maintain simulation configuration tuple $C_k = (q_{active}, w_{remaining}, k)$ where $C_0 = (q_0, w, 0)$ and $C_{k+1}$ is computed via transition rule evaluation $\delta(q_{active}, w[0])$.

#### 3. Formal Inputs
- Target Automaton $M$.
- Input string $w$.
- Control Command (`STEP_FORWARD`, `STEP_BACKWARD`, `PLAY`, `PAUSE`, `RESET`, `JUMP_TO_STEP`).

#### 4. Formal Outputs
- Updated configuration snapshot $C_k$ and updated `ISimulationTrace`.

#### 5. Preconditions
- Model $M$ passes critical validation checks (valid $q_0$).

#### 6. Postconditions
- Simulation state matches exact step configuration $C_k$.

#### 7. Internal State Representation
- `trace`: Immutable `ISimulationTrace` log.
- `playback_index`: Integer $0 \le k \le |w|$.
- `playback_status`: Enum (`STOPPED`, `PLAYING`, `PAUSED`, `HALTED`).

#### 8. Required Data Structures
- Step Snapshot Array.
- Undo/Redo State History Stack.

#### 9. Complete Step-by-Step Algorithm
1. **Command == `START`**:
   a. Compute full trace $T \leftarrow \text{ExecuteSimulation}(M, w)$.
   b. Set `playback_index` $\leftarrow 0$, `playback_status` $\leftarrow$ `PAUSED`.
2. **Command == `STEP_FORWARD`**:
   a. If `playback_index` $< |T.steps|-1$: `playback_index` $\leftarrow$ `playback_index` + 1.
3. **Command == `STEP_BACKWARD`**:
   a. If `playback_index` $> 0$: `playback_index` $\leftarrow$ `playback_index` - 1.
4. **Command == `JUMP_TO_STEP(k)`**:
   a. Set `playback_index` $\leftarrow \max(0, \min(k, |T.steps|-1))$.
5. **Command == `RESET`**:
   a. Set `playback_index` $\leftarrow 0$, `playback_status` $\leftarrow$ `STOPPED`.
6. Return $T.steps[playback\_index]$.

#### 10. Intermediate States
- Re-hydrates workspace views to matches step snapshot $C_k$.

#### 11. Determinism Rules
- Pre-computing full immutable trace $T$ guarantees forward and backward stepping yields identical configurations.

#### 12. Validation Rules
- Command bounds enforced ($0 \le k \le |T.steps|-1$).

#### 13. Error Conditions
- `ERR_SIMULATION_INVALID_STEP`: Requested step index out of bounds.

#### 14. Edge Cases
- Stepping backward past Step 0 remains clamped at Step 0.

#### 15. Time Complexity
- Step Navigation: $O(1)$ random access to pre-computed step array.

#### 16. Space Complexity
- Memory Usage: $O(|w|)$.

#### 17. Correctness Guarantees
- Replay Rule Theorem: $C_k$ is invariant under forward/backward stepping operations.

#### 18. Trace Generation Rules
- Emits immutable `IExecutionStep` for presentation view rendering.

#### 19. AI Explanation Hooks
- `hook_explain_step_change`: Sends step configuration $C_k$ to AI Tutor.

#### 20. Unit Test Requirements
- Test forward stepping to end of string.
- Test backward stepping to Step 0.
- Test jump to arbitrary step index.

#### 21. Acceptance Criteria
- **Given** a 4-step simulation at step 2, **When** `STEP_BACKWARD` is called, **Then** step index becomes 1 and configuration matches step 1.

#### 22. Complete Worked Example
- Trace: $S_0(q_0) \to S_1(q_1) \to S_2(q_0)$. `playback_index` = 2.
- Command: `STEP_BACKWARD` $\implies$ `playback_index` = 1.
- View re-hydrated to $S_1(q_1)$.

## SECTION 8: Mathematical Equivalence Algorithms

### 8.1 Automata Equivalence & Isomorphism

#### 1. Objective
Determine whether two DFAs $M_1$ and $M_2$ accept the exact same language ($L(M_1) = L(M_2)$) or are structurally isomorphic.

#### 2. Mathematical Definition
1. **Language Equivalence**: $L(M_1) = L(M_2) \iff L(M_1) \triangle L(M_2) = \emptyset$, where $\triangle$ is symmetric difference $(L_1 \cap \bar{L}_2) \cup (\bar{L}_1 \cap L_2)$.
2. **Automata Isomorphism**: Bijective mapping $f: Q_1 \to Q_2$ such that $f(q_{0,1}) = q_{0,2}$, $f(F_1) = F_2$, and $f(\delta_1(q, a)) = \delta_2(f(q), a)$.

#### 3. Formal Inputs
- Candidate DFAs $M_1 = (Q_1, \Sigma_1, \delta_1, q_{0,1}, F_1)$ and $M_2 = (Q_2, \Sigma_2, \delta_2, q_{0,2}, F_2)$.

#### 4. Formal Outputs
- Boolean equivalence flag `isEquivalent` and counter-example string $w_{counter} \in \Sigma^*$ if not equivalent.

#### 5. Mandatory Preconditions & Totalization Pipeline
- **Shared Alphabet Alignment**: Let $\Sigma \leftarrow \Sigma_1 \cup \Sigma_2$. Both DFAs are aligned to the unified alphabet $\Sigma$.
- **Mandatory Totalization Precondition**: Before product state space construction, both DFAs MUST be totalized over $\Sigma$. If any state $q \in Q_i$ lacks a transition for a symbol $a \in \Sigma$, a deterministic sink state ($q_{dead, i}$) MUST be injected:
  - Add $q_{dead, i}$ to $Q_i$.
  - For any missing transition $(q, a)$, set $\delta_i(q, a) \leftarrow q_{dead, i}$.
  - For all $a \in \Sigma$, set $\delta_i(q_{dead, i}, a) \leftarrow q_{dead, i}$.
  - $q_{dead, i} \notin F_i$ (sink states are non-accepting).

#### 6. Complete Step-by-Step Algorithm (Product Automaton)
1. Totalize $M_1$ and $M_2$ over unified alphabet $\Sigma$.
2. Construct product state space $Q_P = Q_1 \times Q_2$.
3. Run BFS starting from initial pair $(q_{0,1}, q_{0,2})$.
4. Maintain visited set of state pairs.
5. For each visited pair $(p, q)$:
   a. Check if one state is accepting and the other is non-accepting:
      - If $(p \in F_1 \land q \notin F_2)$ or $(p \notin F_1 \land q \in F_2)$:
        - Reconstruct path from start pair to $(p, q)$ to extract counter-example string $w_{counter}$.
        - Return `{ isEquivalent: false, counterExample: w_counter }`.
   b. For each symbol $a \in \Sigma$ (in lexicographical order):
      - Next pair $(p', q') \leftarrow (\delta_1(p, a), \delta_2(q, a))$.
      - If $(p', q')$ not visited, mark visited and push to BFS queue.
6. If BFS completes without finding a mismatch pair, Return `{ isEquivalent: true }`.

#### 6. Complexity
- Time Complexity: $O(|Q_1| \cdot |Q_2| \cdot |\Sigma|)$.
- Space Complexity: $O(|Q_1| \cdot |Q_2|)$.

## SECTION 9: Regular Expression Parser & AST

### 9.1 RegEx Grammar & AST Construction

#### 1. Objective
Parse raw regular expression strings into an Abstract Syntax Tree (AST) using formal operator precedence rules.

#### 2. Formal Context-Free Grammar
$$\begin{aligned}
E &\to T \text{ (`+` } T)^* \quad &&\text{(Union / Disjunction)} \\
T &\to F \text{ (} F )^* \quad &&\text{(Concatenation)} \\
F &\to K \text{ (`*`)}^* \quad &&\text{(Kleene Star)} \\
K &\to \sigma \mid \varepsilon \mid \text{`(` } E \text{ `)`} \quad &&\text{(Base Symbol / Grouping)}
\end{aligned}$$

#### 3. Operator Precedence & Associativity
1. **Parentheses `()`**: Highest precedence, explicit grouping.
2. **Kleene Star `*`**: Postfix unary, left-associative, highest operator binding.
3. **Concatenation `·`**: Implicit binary, left-associative, medium binding.
4. **Union `+` / `|`**: Explicit binary, left-associative, lowest binding.

#### 4. AST Node Definitions
- `UnionNode(left: ASTNode, right: ASTNode)`
- `ConcatNode(left: ASTNode, right: ASTNode)`
- `StarNode(child: ASTNode)`
- `SymbolNode(symbol: string)`
- `EpsilonNode()`

## SECTION 12: AI Gateway Integration & Anti-Hallucination Contracts

### 12.1 Authoritative Trace Boundaries & Deterministic Verification Workflow (`ITraceVerifier`)
- **Exposed Data to AI**:

  - Immutable execution trace payload (`ISimulationTrace`).
  - Validation diagnostics array (`IValidationIssue[]`).

- **Authoritative Trace Rule**:

- **Deterministic `ITraceVerifier` Verification Workflow**:
  1. **Parse AI Response**: Intercept streamed or completed AI response text.
  2. **Fact Extraction**: Extract all referenced:
     - State identifiers ($q_0, q_1, \dots$)
